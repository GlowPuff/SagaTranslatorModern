# Saga Translator (DEPRECATED, USE THE WEB APP VERSION)
Simplify the translation of Imperial Commander 2 Saga language files. Every language file used by Imperial Commander 2 is supported by this Translator app.

### Download (Windows only [deprecated])
[Download Current Release](https://github.com/GlowPuff/SagaTranslatorModern/releases)

### Web Version
The web app version of the Translator is preferred and regularly updated, [available here](https://sagatranslatorweb.pages.dev/).  Its functionally is identical to the Windows version, runs in your web browser, and can be used on any operating system.
